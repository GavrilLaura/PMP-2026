# Laborator 8 - Programare probabilista folosind PyMC
 
Valoarea observata Y muta distributia a posteriori a lui n: cu cat Y este mai mare, cu atat n este mai mare, deoarece nu pot cumpara mai multi clienti decat au intrat in magazin (n >= Y). Probabilitatea θ are efectul invers: pentru acelasi Y, un θ mic inseamna ca putini clienti cumpara, deci au trebuit sa intre mai multi clienti, iar distributia lui n se muta spre dreapta. In plus, un θ mic face distributia mai larga, adica estimarea lui n este mai nesigura, pentru ca multi clienti care nu cumpara nu apar in Y. De exemplu, pentru Y = 5 media a posteriori este aproximativ 13 cand θ = 0.2 si aproximativ 10 cand θ = 0.5.
